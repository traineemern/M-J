This directory holds optimized images for the M&M Water Wells website.

Replace placeholder images with real photos:
- hero-bg.webp — A hero background (drill rig in action, clean water, etc.)
- og-preview.webp — Open Graph preview image for social sharing (1200x630)
- truck.webp — Company service truck or drill rig photo
- team.webp — Team / crew photo (optional)

Image guidelines:
- Use WebP format for best compression
- Keep files under 200 KB each
- Include width and height attributes in <img> tags
- Use meaningful alt text that describes the image content
